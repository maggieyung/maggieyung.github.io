### 🫧 Guestbook

Browser-based collaborative guestbook where people can leave notes, write, and draw together simultaneously in real-time on shared 2D/3D canvases!

### 💌 Features

- **Collaborative drawing:** Multiple users draw at once with low-latency updates
- **Tools:** 
    - Pen, Pencil, Eraser with pressure curve and adjustable settings (size, opacity, flow)
    - Color picker + eyedropper: Colorwheel and eyedropper
- **Paint notes:** Freehand drawing canvas with undo/redo history
- **Text notes:** Simple text content
- **Image notes:** Add images
- **3D canvases:** Cube, sphere, and 2.5D modes, draw on any 2D plane within 3D scene
- **Presence cursors:** Anonymous cursors and activity feedback
- **Context menu:** Page menus for quick actions



### 🎐 Technologies

- **JavaScript** 
- **HTML/CSS** 
- **WebGL** and **Three.js**
- **Firebase Realtime Database**

### 🍀 Keyboard & Mouse Shortcuts

- **b:** Switch to Pen
- **p:** Switch to Pencil
- **e:** Switch to Eraser
- **Ctrl/Cmd + z:** Undo
- **Ctrl/Cmd + y:** Redo
- **h:** Flip horizontally
- **n:** New text note
- **d:** New paint note
- **i:** New image note
- **MB2 (right mouse button):** Open the context menu
- **Shift + MB1 (left mouse button):** Rotate 3D scene
- **Drag note corners:** Resize note
